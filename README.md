Overview
This repository documents my contributions as Network Operations Center (NOC) Manager during the Network Security and Cybersecurity Vulnerability Assessment conducted by the National Cyber Security Authority (NCSA) on the Liquid Telecom Rwanda network infrastructure.
Position
Network Operations Center (NOC) Manager
Project Description
The assessment aimed to evaluate the security posture of network infrastructure, identify vulnerabilities, assess operational security controls, review network exposure, and recommend corrective actions to strengthen cyber resilience and compliance.
Key Contributions
1. Assessment Coordination
•	Coordinated engagement between NCSA assessors and internal technical teams.
•	Facilitated access to required network information and operational documentation.
•	Scheduled assessment activities and stakeholder meetings.
•	Ensured timely communication between assessed departments and security auditors.

2. Network Infrastructure Support
•	Provided network topology information and infrastructure overview.
•	Shared architecture details for IP Core, MPLS, Internet, Enterprise, FTTH, and Transmission networks.
•	Assisted in identifying critical network assets and service dependencies.
•	Supported validation of network segmentation and security boundaries.

3. Vulnerability Assessment Support
•	Assisted assessors in vulnerability discovery and verification activities.
•	Reviewed identified network vulnerabilities and potential operational impacts.
•	Supported risk classification and prioritization discussions.
•	Validated findings against operational network configurations.

4. Security Controls Review
Participated in the review of:
•	Firewall security controls
•	Router and switch hardening practices
•	Network access controls
•	Monitoring and alerting mechanisms
•	Remote access security controls
•	Incident response procedures

5. Risk Management & Remediation
•	Reviewed assessment findings with technical teams.
•	Assisted in developing remediation plans for identified vulnerabilities.
•	Tracked corrective actions and implementation progress.
•	Monitored closure of security recommendations.
6. Operational Security Assurance
•	Ensured assessment activities were conducted without negatively impacting production services.
•	Evaluated operational risks associated with remediation activities.
•	Coordinated change management requirements for security improvements.
7. Continuous Improvement
•	Contributed to strengthening cybersecurity awareness within operational teams.
•	Recommended improvements to monitoring, vulnerability management, and incident response processes.
•	Supported enhancement of network security governance and operational procedures.
